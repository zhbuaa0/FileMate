# FileMate

一个在 Windows 和 macOS 上运行的本地批量文件加密、解密应用。界面和文件处理都在本机完成，不上传数据。

## 运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm start
```

## 使用

1. 选择“加密文件”或“解密文件”。
2. 优先选择文件夹；应用会递归扫描所有子目录，也可单独添加文件。
3. 输入同一批文件使用的密码，可选择单独的输出文件夹。
4. 点击开始；原文件始终保留，不会被覆盖或删除。

文件夹本身不会被打包或加密。Word、PDF、压缩包及其他普通文件都会逐个处理；已有 `.sbox` 会跳过，避免重复加密。加密结果使用 `.sbox` 后缀，解密时若目标文件已存在，应用会自动生成带序号的新文件名。

## 安全设计

- AES-256-GCM 同时保护内容机密性和完整性。
- 每个文件使用独立的随机 salt 和 nonce，密码通过 scrypt 派生密钥。
- 大文件流式处理，不必一次载入内存。
- 解密先写入隐藏临时文件；只有完整性验证通过后才生成结果。
- Electron 渲染进程启用沙箱和上下文隔离，仅暴露必要的文件选择与任务接口。

密码无法恢复。文件名和文件大小不会被隐藏；如需隐藏这些信息，请先把文件打包成压缩包再加密。

## 自检与打包

```bash
npm test

# 在 macOS 上生成 DMG
npm run dist:mac

# 在 Windows 上生成 x64 NSIS 安装包
npm run dist:win

# 在任意支持的构建机上生成 Windows x64 便携 ZIP
npm run dist:win:portable
```

安装包输出到 `dist/`。正式分发前还需配置 Apple 公证/签名与 Windows 代码签名；建议分别在对应操作系统上构建并验收。
